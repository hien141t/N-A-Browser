🔌 Base URL
http://127.0.0.1:9399
ℹ️ API chỉ lắng nghe trên 127.0.0.1 (localhost) — hoàn toàn an toàn, không lộ ra internet. Khởi động tự động khi mở N/A Browser.

📋 Danh sách Endpoints

MethodEndpointMô tả
GET/api/statusKiểm tra server, đếm profiles/running
GET/api/profilesLấy toàn bộ danh sách profile
GET/api/profiles/:idLấy 1 profile theo ID
POST/api/profilesTạo mới profile
DELETE/api/profiles/:idXóa profile + thư mục data
GET/api/devicesLấy danh sách device hỗ trợ

✨ POST /api/profiles — Tạo Profile

Request Body (JSON)

FieldTypeBắt buộcMô tả
namestring✓ Bắt buộcTên profile
deviceIdstringOptionalID device (random nếu bỏ qua)
proxystring|objectOptionalProxy dạng host:port:user:pass hoặc object
cityKeystringOptionalMã tỉnh thành (hcm, hn, dn...) — random nếu bỏ qua
startUrlstringOptionalURL mở khi launch browser
notesstringOptionalGhi chú
selectedExtensionsstring[]OptionalMảng ID extension muốn gán

  }'

import requests

📋 GET /api/profiles — Lấy danh sách

cURL 
curl http://127.0.0.1:9399/api/profiles
Python 
import requests
profiles = requests.get("http://127.0.0.1:9399/api/profiles").json()
print(f"Tổng: {profiles['total']} profiles")
for p in profiles['profiles']:
    print(p['id'], p['name'])

🔀 Định dạng Proxy hỗ trợ

Các format hợp lệ
// String format:
"113.187.249.230:20028"                       // host:port
"113.187.249.230:20028:user:pass"              // host:port:user:pass
"http://user:pass@113.187.249.230:20028"       // URL format
"socks5://user:pass@113.187.249.230:1080"      // SOCKS5

// Object format:
{ "type": "http", "host": "113.187.249.230", "port": 20028, "user": "u", "pass": "p" }
